# Sales & Profit Performance Dashboard (Excel)

## Project Overview

This project analyzes sales transactions across products, categories, and salespersons using Microsoft Excel.

The dashboard provides interactive insights into sales performance, profitability, product trends, and salesperson performance.

---

## Business Questions Answered

- What are the total Sales, Boxes, and Profitability?
- Which products generate the highest sales?
- Which salespersons perform best?
- How do sales and profits trend over time?
- Which categories contribute most to revenue?

---

## Dashboard Features

### KPI Reporting
- Total Sales
- Total Boxes
- Profit %

### Product Analysis
- Top 5 Products by Sales
- Product Profitability Analysis

### Trend Analysis
- Monthly Sales Trend
- Monthly Profit Trend
- Monthly Box Trend

### Salesperson Analysis
- Sales Performance
- Expenses
- Profit
- Profit %
- Boxes

### Interactive Features
- Category Slicer
- Product Slicer
- Conditional Formatting
- Data Bars
- KPI Indicators

---

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Model
- Measures
- Conditional Formatting
- Slicers
